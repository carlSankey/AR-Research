# Sources

- **ardungeon** – disassembly of the 8-bit *Dungeon*, split into overlays (file names like `22-s432.asm`). Grep the overlay files for in-game text. Overlays used here: 31-s115 (item / treasure tables), 22-s168 (Clothes Horse), 22-s323 (King Danjor), 22-s365 (Great Dragon), 22-s094 (Gargoyle), 22-s409 (Death's Door), 22-s432 (Alien Control Room), 32-s091 (Acrinimiril's tomb), 32-s126 (Ozob / prison), 32-s327 (Oracle), 32-s575 (rumours).
- **Kroah's Game Reverse Engineering – Alternate Reality**: http://bringerp.free.fr/RE/Ar/news.php5 – the Atari ST *City* v2.0; links to Jim Norris's 8-bit City disassembly.
- **The Dungeon cluebook**: http://www.eobet.com/alternate-reality/docs/dungeon_cluebook.html
- **CRPG Addict, "Alternate Reality: The Dungeon – Won" (2017)**: http://crpgaddict.blogspot.com/2017/04/alternate-reality-dungeon-won-with.html
- Original *City* guidebook and *Dungeon* handbook (manuals).
